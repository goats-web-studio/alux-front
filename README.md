# Alux.kz — сайт

Next.js 16 (App Router, SSR/SSG + ISR), React 19, Tailwind 4. Контент и заявки — в бэкенде `lifts-back`.

## Запуск

```bash
cp .env.example .env.local   # NEXT_PUBLIC_API_URL, NEXT_PUBLIC_SITE_URL, REVALIDATE_SECRET
npm install
npm run dev                  # http://localhost:3000 (бэкенд должен работать на :4000)
```

Продакшен: `npm run build && npm start` (или pm2: `pm2 start npm --name alux-front -- start`).

Админка — `/admin` (логин и пароль задаются в `.env` бэкенда).

## Страницы

| Путь | Что там |
|---|---|
| `/` | Первый экран, каталог, преимущества, объекты, этапы работы, квиз «Расчёт стоимости», профильные системы, сертификаты, FAQ, контакты |
| `/catalog`, `/catalog?category=…` | Каталог с фильтром по категориям (работает без JS) |
| `/catalog/[slug]` | Страница товара: фото, цена, характеристики, описание, похожие, заявка / WhatsApp |
| `/blog`, `/blog/[slug]` | Блог |
| `/privacy` | Политика обработки персональных данных |
| `/admin/*` | CMS: сводка, заявки, каталог, объекты, блог, FAQ, профильные системы, сертификаты, настройки |

## Как устроено

- Все публичные страницы рендерятся на сервере; данные кэшируются (`revalidate: 300`, теги `cms` + раздел).
  После правок в админке бэкенд вызывает `POST /api/revalidate` с секретом — кэш сбрасывается сразу.
- Если бэкенд недоступен, сайт не падает: используются настройки по умолчанию, пустые разделы скрываются.
- Заявки: одна модалка на весь сайт (`openLead()` из `components/lead/lead-dialog.tsx`), формы в контактах и квизе.
  В каждой заявке передаётся источник (`hero`, `contacts`, `product`, `quiz`, `blog`, `callback`, `project`)
  и товар, который интересует клиента.
- SEO: метаданные и canonical на всех страницах, Open Graph, `sitemap.xml`, `robots.txt`,
  JSON-LD (организация, товар, хлебные крошки, статья, FAQ).
- Дизайн-токены — в `app/globals.css` (`@theme`): графит `ink-*`, золото `gold-*` (из логотипа), тёплый фон `paper`.
  Шрифты — Unbounded (заголовки) и Manrope (текст).
