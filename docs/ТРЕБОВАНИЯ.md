# Что нужно для запуска сайта Alux.kz

Чем полнее материалы, тем быстрее запуск. Всё, что отмечено ★, — обязательно.

## 1. Бренд

- ★ Логотип в векторе (SVG, AI, PDF или CDR). Сейчас есть только аватар из Instagram.
- Фирменные цвета (если есть брендбук). Если нет — используем графит + золото с логотипа.

## 2. Контакты

- ★ Телефоны для сайта (1–2 номера).
- ★ Номер WhatsApp для кнопки «Написать» на сайте.
- ★ Номера WhatsApp менеджеров, которым будут приходить заявки (1–5 номеров).
- ★ Адрес офиса / производства / шоурума и часы работы.
- Ссылка на организацию в 2ГИС (для карты и отзывов).
- Email.
- Юридическое название компании, БИН — для политики конфиденциальности и подвала.

## 3. Фото и видео (самое важное для продаж)

- ★ Фото готовых объектов: минимум 8–10 объектов, по 2–5 фото на каждый.
  - Исходники с телефона или фотоаппарата в максимальном качестве (не скриншоты из Instagram).
  - **Без надписей и стикеров поверх фото** (в Instagram-постах много текста — на сайте он не нужен).
  - Горизонтальные и вертикальные, днём, при хорошем свете.
- По каждому объекту: название/тип (офис, ТЦ, дом), город, год, что сделали (например «120 м² перегородок»).
- Фото производства, команды, замерщика на объекте — повышают доверие.
- Видео с объектов (по желанию) — можно вставить в карточки.

## 4. Каталог и цены

По каждому направлению (перегородки, витражи, двери, входные группы, окна, раздвижные системы и др.):

- ★ Название и что входит.
- ★ Ориентировочная цена «от … ₸/м²» или «от … ₸» (или решение не показывать цены — тогда «цена по замеру»).
- Характеристики: профиль, стекло, толщина, фурнитура, цвета, сроки изготовления, гарантия.
- С какими профильными системами работаете (Alutech, Realit, Reynaers, Schüco… — сейчас на сайте примеры, заменим на реальные).

## 5. Цифры и факты (проверить/заменить заглушки)

- ★ Лет на рынке (в Instagram — «более 15 лет»).
- Сколько объектов сделано.
- Гарантия на конструкции и монтаж (сейчас на сайте заглушка «5 лет»).
- Сроки изготовления (сейчас «от 10 рабочих дней»).
- Условия оплаты: предоплата, рассрочка, работа с НДС.
- География: Астана + какие города.

## 6. Документы

- Сертификаты соответствия, паспорта качества на стекло/профиль, письма от производителей (сканы PDF/JPG).
- Отзывы клиентов (текст + имя/компания, можно скриншоты) — по желанию.

## 7. Доступы и сервисы

- ★ **Домен** — например `alux.kz` (сейчас занят сторонней компанией Atalux), варианты: `alux-kz.kz`, `aluxglass.kz`, `alux.com.kz`.
- ★ **Сервер (VPS)** — или мы подберём и оформим на вас:
  - Ubuntu 22.04/24.04, 1–2 vCPU, 2 ГБ RAM, 20 ГБ SSD, желательно дата-центр в Казахстане;
  - на нём будет: Node.js 24, nginx, SSL (Let's Encrypt), pm2, ежедневный бэкап.
- ★ **WhatsApp для уведомлений:** отдельная сим-карта с WhatsApp (рекомендуем не личный номер) —
  к ней подключается Green API по QR-коду. Регистрация на green-api.com и оплата тарифа — на клиенте.
- Яндекс Метрика и Google Analytics — создадим сами или дайте доступ к существующим.
- Google Search Console и Яндекс Вебмастер — для индексации.

## 8. Технические требования к сайту (что мы гарантируем)

| Требование | Реализация |
|---|---|
| Скорость | Серверный рендеринг, кэш страниц, лёгкие шрифты и изображения |
| Адаптивность | 360 px → 2560 px, отдельные мобильные сценарии (свайп-карусели, мобильное меню) |
| SEO | Мета-теги, canonical, sitemap.xml, robots.txt, микроразметка Schema.org |
| Заявки | Сохраняются в базе + дублируются в WhatsApp; антиспам; выгрузка в Excel |
| Управление | Админка для всего контента без программиста |
| Безопасность | HTTPS, JWT-авторизация, защита от подбора пароля, проверка загружаемых файлов |
| Персональные данные | Согласие в формах, политика обработки ПД по законодательству РК |
| Резервные копии | Ежедневный бэкап базы и файлов |
| Браузеры | Последние версии Chrome, Safari (iOS/macOS), Edge, Firefox, Яндекс Браузер |
